MaxModel reads your Mac's chip, memory, and memory speed, picks the most capable open model that runs well on it, and downloads it. Then you chat with it entirely on your Mac, and drop in screenshots, photos, and PDFs to ask about them. No account, no subscription, no cloud.

![MaxModel recommending the best model for a 16 GB M4 Mac](site/assets/screenshot.png)

## Features

- **Picked for your hardware.** Compares open models on published benchmarks and keeps only those that fit your Mac's memory and still answer at a comfortable pace, so a bigger model isn't chosen just because it fits.
- **Sees what you share.** Models that can see look at images directly; others read the text in them. PDFs work too, including scans.
- **Private by design.** Every answer is generated on your Mac. Chats, images, and documents never leave it.
- **75 open models, verified.** Qwen, Gemma, Llama, Mistral, Phi, gpt-oss, and more, each pinned to an exact file and checked against its hash. Licenses are shown before download.
- **Stays current.** MaxModel asks once whether to check for updates. Every update is signed and verified before it installs.

## Getting started

1. [Download MaxModel](https://dhrubsingh.github.io/maxmodel/), unzip it, and move it to Applications.
2. Open it. MaxModel recommends a model for your Mac; click **Get it**.
3. Once it's downloaded, start chatting. Everything works offline from then on.

> **Opening it the first time:** early builds aren't notarized by Apple yet, so macOS says it can't verify the developer. Open MaxModel once, then go to **System Settings → Privacy & Security** and click **Open Anyway**. You only do this once; updates install without it.

The [user guide](docs/using-maxmodel.md) covers everything else, from comparing models to managing storage.

## How it picks a model

1. **Read the Mac:** its chip, how much memory it can give a model, and how fast that memory is.
2. **Rank by evidence:** published MMLU-Pro, IFEval, and GPQA Diamond scores, compared head to head on the benchmarks two models share.
3. **Check it fits and keeps pace:** a model must fit in memory *and* start answering within the goal's wait, since speed depends on memory bandwidth, not just size. Among models within 2 points of the leader, the fastest wins.

What that means on some typical Macs, for the default **Best answers** goal:

| Mac | Recommended | Expected speed |
| --- | --- | ---: |
| M1, 8 GB | Qwen3.5 4B | 14 tokens/s |
| M4, 16 GB | Qwen3.5 4B | 24 tokens/s |
| M4 Pro, 24 GB | Qwen3.5 9B | 26 tokens/s |
| M3 Pro, 36 GB | Qwen3.5 35B-A3B | 44 tokens/s |
| M4 Max, 128 GB | Qwen3.5 35B-A3B | 159 tokens/s |

The full method, including goals, precision, thinking budgets, and its limits, is in [How MaxModel picks a model](docs/recommendations.md).

## Privacy

- Answers are generated by a bundled engine that only accepts connections from your own Mac.
- The only network requests are model downloads you start and, if you allow it, a daily update check. Neither includes your chats.
- No accounts, analytics, or telemetry.
- Chats and attachments are stored in `~/Library/Application Support/MaxModel`, readable only by you.

Details: [Privacy and security](docs/privacy-and-security.md).

## Contributing

MaxModel is open source, and contributions are welcome, with or without code. Bug reports, results from your Mac, model suggestions, docs fixes, and pull requests all help. Help is especially wanted with **testing on Intel Macs**, **image support for more models**, and **sourcing benchmark scores** for the 26 models that can't be ranked yet.

Build it in three commands:

```sh
git clone https://github.com/dhrubsingh/maxmodel.git && cd maxmodel
python3 scripts/fetch-engine.py
MAXMODEL_DATA_DIR="$PWD/.test-data/dev" swift run Hearth
```

Then read **[CONTRIBUTING.md](CONTRIBUTING.md)** for setup, step-by-step recipes (adding a model, adding benchmark scores, changing the interface), and the pull request checklist. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md), and report security issues privately as described in [SECURITY.md](SECURITY.md).
